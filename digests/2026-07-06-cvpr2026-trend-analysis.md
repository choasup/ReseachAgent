## 核心结论

1. **推理/RL 是年度最大爆点**：占比 1.81% → 8.69%（52 → 353 篇，近 7 倍）。
   RL、test-time scaling、CoT 正从 LLM 社区全面涌入视觉。
2. **VLM/MLLM 成为"底座"**：占比 6.89% → 10.0%，且与推理（80 篇共现）、具身（45）、
   医学（35）、效率（35）全面耦合——它不再是一个"方向"，而是其他方向的基础设施。
3. **Agent 快速起量**：1.04% → 2.76%（30 → 112 篇），GUI/工具调用/多模态 agent 为主力。
4. **生成仍是第一大块但进入平台期**：Diffusion/生成占 22.87%（-0.88pp）；
   增长转向"生成×效率""生成×推理"等交叉。
5. **经典感知继续退潮**：低层视觉 -1.31pp、少/零样本 -1.19pp、点云 -1.02pp、
   3DGS/NeRF -0.84pp。纯任务型工作让位于"底座+应用"。
6. **最强共现 = 应用落地**：分割×医学(151)、Diffusion×视频生成(121)、VLM×推理(80)、
   Diffusion×医学(67)——横跨"底座与领域"的论文是主流形态。
