# ReseachAgent · AI 研究知识库

一个基于 **Claude Code** 的 AI 研究助手 + 知识库。它不是一个独立运行的程序，而是一套
**仓库约定 + 模板 + 工作流（slash 命令）**：你在 Claude Code 里提需求，我按这里的规则帮你
搜论文、解读、归档，所有产物都是可检索、可 git 追溯的 Markdown。

## 能做什么

- 🔍 **找论文**：给方向或关键词，从 arXiv / 网络搜索最新工作
- 📖 **解读论文**：给 PDF / 链接 / arXiv ID，产出结构化中文解读并归档到 `papers/`
- 🧭 **追踪主题**：维护若干研究方向，定期拉取新进展（见 `topics/`）
- 🗞️ **生成简报**：把一段时间内的新论文汇总成 digest（见 `digests/`）
- 🧠 **当知识库用**：基于已归档内容回答问题、做横向对比、找关联

## 目录结构

```
.
├── CLAUDE.md            # ⭐ Agent 行为约定（最重要，定义我怎么干活）
├── INDEX.md            # 知识库总索引（每次归档后更新）
├── papers/             # 论文解读，一篇一文件，按年份分目录
│   └── 2026/
├── topics/             # 主题追踪，一个方向一文件
│   └── topics.yaml     # 追踪清单（订阅哪些方向）
├── digests/            # 定期简报（周报/月报）
├── templates/          # 各类 Markdown 模板
└── .claude/skills/     # 自定义工作流（slash 命令）
    ├── paper/          #   /paper  解读并归档一篇论文
    ├── track/          #   /track  追踪某个主题的新论文
    ├── digest/         #   /digest 生成简报
    └── kb/             #   /kb     检索知识库
```

## 怎么用

在 Claude Code 里直接说，或用 slash 命令：

| 你想做的事 | 这么说 |
|---|---|
| 解读一篇论文 | `/paper https://arxiv.org/abs/2401.xxxxx` 或贴 PDF/链接 |
| 找某方向最新论文 | `/track 长上下文 KV cache 压缩` |
| 出一份本周简报 | `/digest 最近一周` |
| 问知识库 | `/kb 有哪些做投机解码的论文，结论是什么` |

直接用自然语言提需求也行，slash 命令只是固定下来的常用流程。

## 设计原则

1. **纯 Markdown，无外部依赖** —— 知识库就是文件，git 即版本管理，随时可迁移。
2. **结构化优先** —— 每篇解读用统一模板，便于横向对比和检索。
3. **可追溯** —— 每个结论都带原文出处/链接，避免知识库变成"幻觉库"。
4. **增量积累** —— 越用越值钱，`INDEX.md` 始终反映全貌。
