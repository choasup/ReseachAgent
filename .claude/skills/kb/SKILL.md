# /kb — 检索知识库

输入：问题或关键词（`$ARGUMENTS`）。

## 步骤

1. **定位**：用 `Grep` / `Glob` 在 `papers/`、`topics/`、`INDEX.md` 中搜相关笔记。
   先看 `INDEX.md` 找方向，再读具体笔记。
2. **综合回答**：跨多篇整合；横向对比用表格（方法 / 结论 / 数字 / 出处）。
3. **引用来源**：每个结论标明出自哪篇笔记（带路径），让用户能溯源。
4. **诚实兜底**：库里没有就明说"知识库暂无相关内容"，并提议 `/track` 或 `/paper` 去补。

## 注意
- 只基于已归档内容回答，不要用模型记忆冒充知识库内容。
- 区分"库里的结论"和"我的补充判断"。
