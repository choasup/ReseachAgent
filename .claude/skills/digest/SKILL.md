# /digest — 生成研究简报

输入：时间范围（如"最近一周"/"6 月"，`$ARGUMENTS`），默认最近一周。

## 步骤

1. **收集素材**：
   - `papers/` 中归档日期落在该时间窗内的解读（看 frontmatter `archived`）。
   - `topics/` 中该时间窗内的追踪记录。
2. **组织内容**：复制 `templates/digest.md`。
   - 按主题分组，每条一句话结论 + 链接 + 本库笔记链接。
   - 挑出"本期重点"（1–3 条最重要的，说清为什么）。
3. **归档**：写到 `digests/<今天日期>-<weekly|monthly>.md`。
4. **回复用户**：给精简版（本期重点 + 各主题各 1–2 条），附完整简报路径。

## 注意
- 只汇总库里已有内容；若时间窗内没归档东西，提示用户先 /track 或 /paper。
